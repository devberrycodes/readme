# Hi, I'm DevBerry 👋

I'm a frontend developer working mostly in **React**, **Next.js**, and **TypeScript**, with a particular focus on interfaces that are polished, accessible, and genuinely nice to use — not just functional.

I care about the full loop: what the user sees, what they can do, and how it behaves under edge cases. That means I don't stop at "the UI looks right" — I think about state, accessibility, responsiveness, and how a feature holds up once real data and real users touch it. I'm also branching into backend basics (Supabase, auth) so I can own more of a feature end to end.

## What I'm about

- Building real features (auth flows, dashboards, habit tracking, ticketing) rather than isolated UI demos
- Accessibility as a default, not an afterthought — semantic HTML, keyboard navigation, focus states, ARIA where it matters
- Testing that actually covers the app — unit, integration, and E2E (Vitest, Playwright)
- Comfortable stepping outside React — I've worked in Angular and vanilla JS/HTML/CSS too, because fundamentals matter more than the framework
- Growing into full-stack — increasingly working with backends and databases to own more of the product, not just the frontend layer

## Tech Stack
**Frontend:** React, Next.js, TypeScript, JavaScript, Tailwind CSS, HTML, CSS
**Testing:** Vitest, Playwright
**Backend/Data:** Supabase, basic Python
**Also comfortable in:** Angular
